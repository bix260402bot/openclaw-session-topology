Discord channel / thread

Where a message enters and where a reply is delivered.

2 · gateway

Routing + agent selection

Chooses one agent, then deterministically derives the session key.

3 · durable bucket

Session key → session ID

The key is the stable address. The ID names the current transcript.

4 · one run

Agent turn

One model/tool loop working against that session's context.

optional · separate work

Agent task / subagent

A child execution with its own session. It can fork context or start isolated.
